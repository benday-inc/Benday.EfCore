Class CoreFieldsAdapterBase<TModel, TEntity, TIdentity>

Adapter base for CoreFields models/entities. Copies the framework-managed fields — Status, the four audit fields, and the optimistic-concurrency token (plus identity, entity → model) — automatically in both directions, leaving subclasses to override only PerformAdapt for their own properties. This is the adapter-tier parallel to CoreFieldsEntityBase<TIdentity>, CoreFieldsDomainModelBase<TIdentity>, and the CoreFields service-layer base.

The framework copy runs via the CopyFrameworkFields(TModel, TEntity) hook, so the override surface is identical to a plain adapter: you still only implement PerformAdapt.

Escape hatches: override CopyFrameworkFields to take full control, and call the granular CopyAuditFields(TModel, TEntity), CopyStatus(TModel, TEntity), and CopyConcurrencyToken(TModel, TEntity) helpers to reuse only the pieces you want. Override everything and you're on your own — nothing forces the helpers on you.
