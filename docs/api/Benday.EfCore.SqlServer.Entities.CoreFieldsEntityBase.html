Class CoreFieldsEntityBase

Entity base class with audit fields (CreatedBy, CreatedDate, LastModifiedBy, LastModifiedDate) and optimistic concurrency via a [Timestamp] column.

Column ordering places audit fields after the entity's own columns so they sort to the end of the table in the database.
