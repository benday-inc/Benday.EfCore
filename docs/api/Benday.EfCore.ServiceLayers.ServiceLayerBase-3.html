Class ServiceLayerBase<TModel, TEntity, TIdentity>

Base service layer. Handles the core flow: validate → get or create entity → adapt → save → copy back IDs.

The service owns the adapter. The repository only deals in entities. The controller/API layer only deals in domain models. The service is the bridge.
