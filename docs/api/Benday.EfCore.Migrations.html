Classes

DefaultDesignTimeDbContextFactory<TContext>

Provider-agnostic design-time DbContext factory base so the EF Core CLI (dotnet ef) can construct a context for generating migrations. Reads a named connection string (default: "default") from appsettings.json plus environment-specific overrides and environment variables.

Provider packages supply the actual provider wiring by overriding ConfigureProvider(DbContextOptionsBuilder<TContext>, string) (for example, SqlServerDesignTimeDbContextFactory in Benday.EfCore.SqlServer calls UseSqlServer). Concrete factories override Create(DbContextOptions<TContext>) to construct the context.
