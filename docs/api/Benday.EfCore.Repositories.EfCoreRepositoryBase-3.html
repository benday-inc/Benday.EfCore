Class EfCoreRepositoryBase<TEntity, TIdentity, TDbContext>

Base repository. Owns the DbContext and handles the add-vs-attach decision based on the IsNew(TEntity) seam.

The identity type is generic (TIdentity). Int consumers use the non-generic EfCoreRepositoryBase<TEntity, TDbContext> shim.
